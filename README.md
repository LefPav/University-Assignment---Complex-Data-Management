This repository contains three Python implementations focusing on complex data management, indexing, and query optimization:

* **Part 1 – Relational Query Optimization:** Implementation of Selection Pushdown and Sort-Merge Semijoin techniques using OpenFlights aviation datasets.
* **Part 2 – Spatial Indexing (R-Tree):** Construction of an R-Tree spatial index using Sort-Tile-Recursive (STR) bulk loading, supporting Window Range, Distance Range, and Best-First k-Nearest Neighbor (kNN) queries.
* **Part 3 – Multidimensional Similarity Search:** Implementation and benchmarking of vector indexing methods (Pivot-based triangle inequality pruning and iDistance), evaluating Range and kNN queries against linear scan.
